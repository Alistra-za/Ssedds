# Security policy

Tessalith is an alpha. Only the latest release gets fixes.

## Reporting a vulnerability

Please report privately, not in a public issue. Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Include the version, what you did, and what happened. A small file that triggers the problem helps (no game assets). Tessalith reads untrusted image, DDS, NIF and plugin files, so crashes and runaway memory on a crafted file are in scope.

You will get a reply when the maintainer has read it; this is a hobby project, so there is no fixed timeline.
