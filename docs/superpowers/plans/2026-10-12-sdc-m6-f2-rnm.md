# sdc M6 Track F2 — RNM normal layers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** sdc finds normal-layer files next to a set's `_n`/`_cnr`. They are `_bump`, `_bump2`, `_detailnorm`, `_detailnorm2`, `_bent` and their masks, with rnm.py aliases and `_n_`/`_cnr_` prefixes. It hides them as their own outputs and blends them into the base normal with RNM before mips. Per-layer settings live in `sdc.toml`, and the GUI edits them in an RNM section of the normal's settings.

**Architecture:**
- **Vocabulary.** A new vocabulary table (`rnm::LAYER_VOCABULARY`) gives layer files a canonical suffix, so they join their set. Their jobs get a new hidden status, `JobStatus::NormalLayer`.
- **Planning.** After shaders and bakes, `rnm::plan::plan_rnm` attaches an `RnmJob` (layer files, masks, AO source) to every base normal job, and attaches the `RNM-*` warnings.
- **Settings.** They are a new `Profile.rnm` (`RnmSpec`, skipped from JSON at its default, so existing profile hashes hold). `rnm.target` is a per-file selector like `reencode`, read from the layer file's own `[files]` entry.
- **Encode.** `rnm::blend::apply` runs on the preprocessed base (DirectX vectors in RGB). It never reads or writes alpha, so the existing mips, renormalise and `_cnr` coat-bake path is unchanged.
- **Staleness.** Layer files join the manifest `sources` with a new `SourceRef.rnm` role. Settings are in the hashed profile.

**Tech Stack:** Rust 2021 workspace. Packages: `engine`, `sdc` (cli) and `sdc-gui` (lib `sdc_gui`). Also used: the `image` 0.25 crate, serde/serde_json/schemars, egui 0.36.2 and egui_kittest 0.36.2.

### Plan rulings (Note W, written by Task 9)

- **W1 Blend point.** The blend runs on the *preprocessed* base: after `preprocess_with`, so after the base's own `flip_green`/`reconstruct_z` and its `resize`, and before the mips. Layers resample to that size. The spec's "base size" is the base as it will be written, so a `half` preset blends at half size, which is cheaper and gives the same result. The base vector is normalised before blending.
- **W2 Escape hatch.** A layer file whose sub-type is set by a rule, `--set` or `[files]` converts on its own, as a packing input does (`resolve_file`). This rescues a real texture that happens to end in `_bent`.
- **W3 Selector.** `rnm.target` is a per-file selector like `reencode`, not a `Profile` field. It is read with `rnm_target_requested` from the layer file's `[files]` entry or a file/path `--set`. A sub-type scope refuses it.
- **W4 Who gets a layer.**
  - A layer with no prefix defaults to `n`, falling back to `cnr` when the set has no `_n` base.
  - Prefixed layers default to their prefix.
  - A layer whose effective targets name no base in the set gets `RNM-NO-BASE`.
  - In one stack, the candidates for one layer id are ranked: a prefix naming this base, then no prefix, then the other prefix, with ties broken by path. The first wins, and each loser gives `RNM-LAYER-SHADOWED` on the base job.
- **W5 Bases.** `n` = `normal`, `pbr_normal`, `landscape_normal`; `cnr` = `coat_normal`. A base job must be planned (not `Error`) and not packed. Any shader `Eye` set makes every layer `RNM-IGNORED-EYE`.
- **W6 Settings shape.**
  - Every `rnm.*` field is optional at its default, and `Profile.rnm` is skipped from JSON at its default, so no existing profile hash changes.
  - `rnm.order` drops duplicates (the first is kept) and appends the missing ids in the default order `bent, bump, bump2, detail, detail2`. The resolved profile stores it normalised, or not at all when it equals the default order.
  - `rnm.*` on a sub-type that cannot be a base is reset to the default, so a global `--set rnm.enabled=false` does not re-hash every diffuse.
- **W7 Ranges.** `rnm.<layer>.strength` must be within 0..=2 and finite. `rnm.bent.ao_power` must be within 0.1..=8. Either one out of range gives `CFG-INVALID`.
- **W8 Bump maths.** The bump slope is computed at the bump's own size: height = mean RGB, `slope = k·(h[+1] − h[−1])`, +v up the image, with green flipped to DirectX. The vectors are then resampled and renormalised. `flip_green` on a bump flips the computed Y (an "invert vertical" escape) and defaults to off: a bump is height, not an OpenGL/DirectX normal, so it never follows the base's `flip_green`. Normal layers default to the base's. A bump mask scales the slope, as rnm.py does.
- **W9 AO.**
  - The AO source is, in order:
    1. the set's raw AO file (vocabulary role `PackingInput(Ao)`), channel R;
    2. otherwise the set's `_rmaos`/`_rfaos` **file**, channel B.
  - It is read only for a `bent` layer in `ao_blend` mode with `rnm.bent.ao = true`.
  - `RNM-AO-MISSING` (info) goes on the base when that mode wants AO and there is none.
- **W10 Resampling.** Downscaling uses `mips::area_resample`. If any axis grows, a new bilinear filter is used (texel centres, clamped edges). Each axis scales independently.
- **W11 GUI.**
  - Layer jobs produce no `TextureItem`. Their set-level warnings (`RNM-NO-BASE`, `RNM-IGNORED-EYE`, `RNM-MASK-ORPHAN`) are kept per set in `PlanView::rnm_notes` and shown under the set grid.
  - Base-level codes show in the RNM section.
  - The target switch writes `rnm.target` on the layer file's key.
- **W12 Versions.** 0.7.0: any set with layers now converts differently. Codes 80.
- **W13 `_norm`.** `_norm` (rnm.py's base name) is a vocabulary term `Normal(None)`, like `_normal`. Its green convention is unstated, so it asks `IN-GREEN-UNSTATED` once. rnm.py reads `_norm` as OpenGL, but sdc does not guess.
- **W14 Memory.** Memory admission counts the base only. Layers load one at a time at encode, which is a `shortcut:` comment in `pipeline.rs`.

## Review Focus

1. **A slider, toggle, order or target edit that does not re-encode.** Every `rnm.*` key is in the hashed profile, and the target changes the `sources` list. Pinned in Task 6 (`edits_re_encode`).
2. **A layer file reaching the encoder as its own output** through a path that skips `NormalLayer`, e.g. an explicit `subtype` on the *base* only. Pinned in Task 3 (`layer_never_writes_alone`) and Task 6 (only `_n.dds` is written).
3. **`_cnr` alpha changed by blending or resampling.** The alpha bytes of a varying-alpha `_cnr` are identical with and without layers at mip 0. Pinned in Task 6 (`cnr_alpha_is_untouched`).
4. **Layers with another aspect ratio or a non-power-of-two size** (e.g. 96×40 onto 64×64): no panic, and the output is the base size. Pinned in Task 5 (`resample_any_size`) and Task 6 (`odd_sizes_convert`).
5. **Bump sign.** A height ramp rising toward the top of the image must tilt the DirectX normal to +Y. Pinned in Task 5 (`bump_ramp_tilts_dx_plus_y`).

        *self == RnmSpec::default()

    /// `order` without repeats (the first wins), then the missing ids in [`LayerId::ORDER`] (DECISIONS Note W6).
    pub fn effective_order(&self) -> Vec<LayerId> {
        let mut v: Vec<LayerId> = vec![];
        for id in self.order.iter().flatten().chain(LayerId::ORDER.iter()) {
            if !v.contains(id) {
                v.push(*id);
            }
        }
        v
    }
    pub fn layer(&self, id: LayerId) -> LayerView {
        let (strength, flip_green, mask) = match id {
            LayerId::Bump => (self.bump.strength, self.bump.flip_green, self.bump.mask),
            LayerId::Bump2 => (self.bump2.strength, self.bump2.flip_green, self.bump2.mask),
            LayerId::Detail => (self.detail.strength, self.detail.flip_green, self.detail.mask),
            LayerId::Detail2 => (self.detail2.strength, self.detail2.flip_green, self.detail2.mask),
            LayerId::Bent => (self.bent.strength, self.bent.flip_green, self.bent.mask),
        };
        LayerView {
            strength: strength.unwrap_or(id.default_strength()),
            flip_green,
            mask,
        }
    }
    pub fn ao_power(&self) -> f64 {
        self.bent.ao_power.unwrap_or(1.5)
    }
}

//! M6 Track F2: RNM normal layers (spec `docs/superpowers/specs/2026-10-12-sdc-m6-f2-rnm-design.md`). Layer files
//! (`_bump`, `_detailnorm`, `_bent`, their masks, rnm.py aliases, `_n_`/`_cnr_` prefixes) join their set, are never
//! written on their own and are blended into the set's base normal before mips.
use crate::config::{LayerId, RnmTarget};
use crate::group::{Vocab, VocabRole};

/// What a layer file is (F2 spec §2.1): its layer, whether it is that layer's mask, and the base its name targets
/// (`_n_` → `N`, `_cnr_` → `Cnr`, none → `None`).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct LayerTerm {
    pub layer: LayerId,
    pub mask: bool,
    pub prefix: Option<RnmTarget>,
}

impl LayerTerm {
    /// The canonical suffix the file counts as in its set: the owner's spelling (`bumpmask2`, `detailnormmask`),
    /// prefixed `n_`/`cnr_` when the name was.
    pub fn canonical(&self) -> String {
        let stem = match self.layer {
            LayerId::Bump => "bump",
            LayerId::Bump2 => "bump",
            LayerId::Detail | LayerId::Detail2 => "detailnorm",
            LayerId::Bent => "bent",
        };
        let two = matches!(self.layer, LayerId::Bump2 | LayerId::Detail2);
        let core = format!(
            "{stem}{}{}",
            if self.mask { "mask" } else { "" },
            if two { "2" } else { "" }
        );
        match self.prefix {
            Some(RnmTarget::N) => format!("n_{core}"),
            Some(RnmTarget::Cnr) => format!("cnr_{core}"),
            _ => core,
        }
    }
}

const fn lt(term: &'static str, layer: LayerId, mask: bool, prefix: Option<RnmTarget>) -> Vocab {
    Vocab {
        term,
        role: VocabRole::NormalLayer(LayerTerm {
            layer,
            mask,
            prefix,
        }),
    }
}

/// Each term three times: bare, `n_` and `cnr_` prefixed.
macro_rules! layer_vocab {
    ($($t:literal => $layer:ident $mask:literal),+ $(,)?) => {
        [$(
            lt($t, LayerId::$layer, $mask, None),
            lt(concat!("n_", $t), LayerId::$layer, $mask, Some(RnmTarget::N)),
            lt(concat!("cnr_", $t), LayerId::$layer, $mask, Some(RnmTarget::Cnr)),
        )+]
    };
}

/// F2 spec §2.1: the owner's ten suffixes, then rnm.py's aliases. Matched longest first ([`split_layer`]), before the
/// exporter vocabulary.
pub static LAYER_VOCABULARY: [Vocab; 51] = layer_vocab![
    "bump" => Bump false,
    "bump2" => Bump2 false,
    "bumpmask" => Bump true,
    "bumpmask2" => Bump2 true,
    "detailnorm" => Detail false,
    "detailnorm2" => Detail2 false,
    "detailnormmask" => Detail true,
    "detailnormmask2" => Detail2 true,
    "bent" => Bent false,
    "bentmask" => Bent true,
    "detail" => Detail false,
    "detail2" => Detail2 false,
    "detail_mask" => Detail true,
    "detail2_mask" => Detail2 true,
    "bump_mask" => Bump true,
    "bump2_mask" => Bump2 true,
    "bent_mask" => Bent true,
];

/// The layer term `stem` ends in (case-insensitive; the longest, so `_cnr_bump` beats `_bump`) and the base before
/// it. A stem that is only a term is left alone.
pub fn split_layer(stem: &str) -> Option<(String, &'static Vocab)> {
    let lower = stem.to_ascii_lowercase();
    LAYER_VOCABULARY
        .iter()
        .filter(|v| {
            let tail = format!("_{}", v.term);
            lower.ends_with(&tail) && lower.len() > tail.len()
        })
        .max_by_key(|v| v.term.len())
        // The tail is ASCII, so the cut falls on a char boundary even in non-ASCII stems.
        .map(|v| (stem[..stem.len() - v.term.len() - 1].to_string(), v))
}

use super::{LayerTerm, RnmAo, RnmFile, RnmJob, RnmLayer};
use crate::codes::{Code, Warning};
use crate::config::{BentMode, LayerId, RnmTarget, Subtype};
use crate::discover::InputFile;

use crate::policy::{rnm_target_requested, JobStatus, ResolveCtx, ResolvedJob, SourceStamp};
use std::collections::BTreeMap;
use std::path::Path;

fn file(p: &Path) -> RnmFile {
    RnmFile {
        path: p.to_path_buf(),
        stamp: SourceStamp::of(p),
    }
}

fn name(p: &Path) -> String {
    p.file_name().unwrap_or_default().to_string_lossy().into_owned()
}

/// A base job of the set: planned, not packed, a sub-type with an `rnm_base`.
fn base_kind(j: &ResolvedJob) -> Option<RnmTarget> {
    if j.pack.is_some() || matches!(j.status, JobStatus::Error { .. } | JobStatus::NormalLayer { .. } | JobStatus::PackingInput { .. }) {
        return None;
    }
    j.profile.subtype.rnm_base()
}

/// The bases a layer feeds: `requested`, else its name's prefix, else `n` falling back to `cnr` (Note W4).
fn targets(term: LayerTerm, requested: Option<RnmTarget>, has_n: bool, has_cnr: bool) -> Vec<RnmTarget> {
    let t = requested.or(term.prefix).unwrap_or(if !has_n && has_cnr { RnmTarget::Cnr } else { RnmTarget::N });
    match t {
        RnmTarget::Both => vec![RnmTarget::N, RnmTarget::Cnr],
        one => vec![one],
    }
}

/// Rank of a candidate for one layer in a base `kind`'s stack, lowest first (Note W4).
fn rank(term: LayerTerm, kind: RnmTarget) -> u8 {
    match term.prefix {
        Some(p) if p == kind => 0,
        None => 1,
        Some(_) => 2,
    }
}

pub fn plan_rnm(
    ctx: &ResolveCtx,
    sets: &[TextureSet],
    files: &[InputFile],
    aliases: &BTreeMap<String, String>,
    jobs: &mut [ResolvedJob],
) {
    for set in sets {
        // (job index, term) of the set's layer files.
        let layers: Vec<(usize, LayerTerm)> = jobs
            .iter()
            .enumerate()
            .filter(|(_, j)| j.set_key == set.key)
            .filter_map(|(i, j)| match j.status {
                JobStatus::NormalLayer { term } => Some((i, term.into())),
                _ => None,
            })
            .collect();
        if layers.is_empty() {
            continue;
        }
        let eye = jobs
            .iter()
            .any(|j| j.set_key == set.key && j.shader.as_ref().is_some_and(|p| p.shader == crate::shader::Shader::Eye));
        if eye {
            for &(i, _) in &layers {
                let msg = format!("{}: eye normals are model-space, so RNM is not applied (F2 spec §2.3)", name(&jobs[i].input));
                jobs[i].warnings.push(Warning::new(Code::RnmIgnoredEye, msg));
            }
            continue;
        }
        let bases: Vec<(usize, RnmTarget)> = jobs
            .iter()
            .enumerate()
            .filter(|(_, j)| j.set_key == set.key)
            .filter_map(|(i, j)| base_kind(j).map(|k| (i, k)))
            .collect();
        let has = |k: RnmTarget| bases.iter().any(|(_, b)| *b == k);
        // Read before any warning is pushed, so no borrow of `jobs` is held across the mutations.
        let reqs: Vec<Option<RnmTarget>> = layers
            .iter()
            .map(|&(i, _)| {
                files
                    .iter()
                    .find(|f| f.path == jobs[i].input)
                    .and_then(|f| rnm_target_requested(ctx, f))
            })
            .collect();
        // Layer files (not masks) with the bases they feed.
        let mut feeds: Vec<(usize, LayerTerm, Vec<RnmTarget>)> = vec![];
        for (&(i, term), &req) in layers.iter().zip(&reqs).filter(|((_, t), _)| !t.mask) {
            let ts: Vec<RnmTarget> = targets(term, req, has(RnmTarget::N), has(RnmTarget::Cnr))
                .into_iter()
                .filter(|t| has(*t))
                .collect();
            if ts.is_empty() {
                let msg = format!("{}: no base normal it targets (_n or _cnr) in its set, so it is not used", name(&jobs[i].input));
                jobs[i].warnings.push(Warning::new(Code::RnmNoBase, msg));
            }
            feeds.push((i, term, ts));
        }
        // Masks pair with the layer of the same id and prefix.
        let mask_of = |term: LayerTerm| {
            layers
                .iter()
                .find(|(_, t)| t.mask && t.layer == term.layer && t.prefix == term.prefix)
                .map(|(i, _)| *i)
        };
        for &(i, term) in layers.iter().filter(|(_, t)| t.mask) {
            if !feeds.iter().any(|(_, t, _)| t.layer == term.layer && t.prefix == term.prefix) {
                let msg = format!("{}: a mask without its layer file, ignored", name(&jobs[i].input));
                jobs[i].warnings.push(Warning::new(Code::RnmMaskOrphan, msg));
            }
        }
        let ao = ao_source(set, files, aliases);
        for &(b, kind) in &bases {
            let mut stack: Vec<RnmLayer> = vec![];
            let mut notes: Vec<Warning> = vec![];
            for id in LayerId::ORDER {
                let mut cands: Vec<&(usize, LayerTerm, Vec<RnmTarget>)> = feeds
                    .iter()
                    .filter(|(_, t, ts)| t.layer == id && ts.contains(&kind))
                    .collect();
                cands.sort_by(|a, c| rank(a.1, kind).cmp(&rank(c.1, kind)).then_with(|| jobs[a.0].input.cmp(&jobs[c.0].input)));
                let Some(&&(win, term, _)) = cands.first() else { continue };
                for &&(lose, _, _) in &cands[1..] {
                    notes.push(Warning::new(
                        Code::RnmLayerShadowed,
                        format!("{} is not used for this normal's {} layer: {} is", name(&jobs[lose].input), id.label(), name(&jobs[win].input)),
                    ));
                }
                stack.push(RnmLayer {
                    id,
                    file: file(&jobs[win].input),
                    mask: mask_of(term).map(|m| file(&jobs[m].input)),

//! M6 Track F2 (spec §3, DECISIONS Note W1, W8, W10): blend RNM layers into a preprocessed base normal. The base is
//! DirectX tangent vectors in RGB (after its own `flip_green`); alpha (A) is never read or written, so a `_cnr`'s
//! coat roughness passes through unchanged. Layers load one at a time, are resampled to the base size, applied and
//! dropped.
use super::{RnmFile, RnmJob, RnmLayer};
use crate::config::{BentMode, LayerId, Profile};
use crate::image::Rgba32F;
use crate::load::load_image;
use crate::mips::area_resample;

type V3 = [f32; 3];

pub(crate) fn unit(v: V3) -> V3 {
    let l = (v[0] * v[0] + v[1] * v[1] + v[2] * v[2]).sqrt();
    if l > 1e-8 {
        [v[0] / l, v[1] / l, v[2] / l]
    } else {
        [0.0, 0.0, 1.0]
    }
}

/// A stored texel (0..1) as a tangent normal at strength `s` (rnm.py / DAZ): `t = (2c − 1)·s`,
/// `n = normalize(t.x, t.y, |t.z| + 1 − s)`; `flip` negates Y (an OpenGL source into DirectX).
pub fn decode(c: [f32; 4], s: f32, flip: bool) -> V3 {
    let y = (2.0 * c[1] - 1.0) * s;
    let t = [(2.0 * c[0] - 1.0) * s, if flip { -y } else { y }, (2.0 * c[2] - 1.0) * s];
    unit([t[0], t[1], t[2].abs() + 1.0 - s])
}

/// Reoriented Normal Mapping (Barre-Brisebois & Hill): `detail` reoriented onto `base`.
pub fn rnm(base: V3, detail: V3) -> V3 {
    let t = [base[0], base[1], base[2] + 1.0];
    let u = [-detail[0], -detail[1], detail[2]];
    let k = (t[0] * u[0] + t[1] * u[1] + t[2] * u[2]) / t[2].max(1e-6);
    unit([t[0] * k - u[0], t[1] * k - u[1], t[2] * k - u[2]])
}

/// Note W8: bump height (mean RGB) to DirectX normals at the bump's own size. Iray's slope `k·(h[+1] − h[−1])` per
/// texel, +v up the image (OpenGL `(−k·du, −k·dv, 1)`), then Y negated for DirectX.
pub fn bump_normals(img: &Rgba32F, k: f32) -> Rgba32F {
    let (w, h) = (img.width as i64, img.height as i64);
    let hgt = |x: i64, y: i64| {
        let p = img.at(x.clamp(0, w - 1) as u32, y.clamp(0, h - 1) as u32);
        (p[0] + p[1] + p[2]) / 3.0
    };
    let mut out = Rgba32F::new(img.width, img.height, [0.0, 0.0, 1.0, 1.0]);
    for y in 0..h {
        for x in 0..w {
            let du = hgt(x + 1, y) - hgt(x - 1, y);
            let dv = hgt(x, y - 1) - hgt(x, y + 1);
            let n = unit([-k * du, k * dv, 1.0]);
            *out.at_mut(x as u32, y as u32) = [n[0], n[1], n[2], 1.0];
        }
    }
    out
}

/// Note W10: `img` at `size`: unchanged when equal, the area filter when no axis grows, else bilinear (texel
/// centres, clamped edges).
pub fn resample(img: Rgba32F, size: (u32, u32)) -> Rgba32F {
    if (img.width, img.height) == size {
        return img;
    }
    if img.width >= size.0 && img.height >= size.1 {
        return area_resample(&img, size, false);
    }
    let (sx, sy) = (img.width as f32 / size.0 as f32, img.height as f32 / size.1 as f32);
    let axis = |o: u32, s: f32, n: u32| {
        let f = ((o as f32 + 0.5) * s - 0.5).clamp(0.0, (n - 1) as f32);
        let i = f.floor() as u32;
        (i, (i + 1).min(n - 1), f - i as f32)
    };
    let mut out = Rgba32F::new(size.0, size.1, [0.0; 4]);
    for y in 0..size.1 {
        let (y0, y1, ty) = axis(y, sy, img.height);
        for x in 0..size.0 {
            let (x0, x1, tx) = axis(x, sx, img.width);
            let (a, b, c, d) = (img.at(x0, y0), img.at(x1, y0), img.at(x0, y1), img.at(x1, y1));
            let px = out.at_mut(x, y);
            for i in 0..4 {
                let top = a[i] + (b[i] - a[i]) * tx;
                let bot = c[i] + (d[i] - c[i]) * tx;
                px[i] = top + (bot - top) * ty;
            }
        }
    }
    out
}

/// rnm.py's bent weight: `strength · (1 − ao)^power · mask`.
fn bent_weight(strength: f32, power: f32, ao: f32, mask: f32) -> f32 {
    strength * (1.0 - ao.clamp(0.0, 1.0)).powf(power) * mask
}

fn load(f: &RnmFile) -> Result<Rgba32F, String> {
    load_image(&f.path)
        .map(|(img, _)| img)
        .map_err(|e| format!("{}: {e}", f.path.display()))
}

/// One channel of `f` at `size`, clamped to 0..1.
fn plane(f: &RnmFile, size: (u32, u32), channel: usize) -> Result<Vec<f32>, String> {
    Ok(resample(load(f)?, size)
        .px
        .iter()
        .map(|p| p[channel].clamp(0.0, 1.0))
        .collect())
}

/// Blend `job`'s layers into `work` in `p.rnm`'s order (F2 spec §3.1).
pub fn apply(work: &mut Rgba32F, job: &RnmJob, p: &Profile) -> Result<(), String> {
    let size = (work.width, work.height);
    let spec = &p.rnm;
    for px in &mut work.px {
        let n = unit([px[0], px[1], px[2]]);
        px[..3].copy_from_slice(&n);
    }
    for id in spec.effective_order() {
        let Some(l): Option<&RnmLayer> = job.layers.iter().find(|l| l.id == id) else {
            continue;
        };
        let v = spec.layer(id);
        let s = v.strength as f32;
        // A bump is height, already DirectX from `bump_normals`: its flip defaults off. Normal layers follow the base (W8).
        let bump = matches!(id, LayerId::Bump | LayerId::Bump2);
        let flip = v.flip_green.unwrap_or(!bump && p.channels.flip_green);
        let mask = match (&l.mask, v.mask) {
            (Some(m), true) => Some(plane(m, size, 0)?),
            _ => None,
        };
        let m = |i: usize| mask.as_ref().map_or(1.0, |v| v[i]);
        match id {
            LayerId::Bump | LayerId::Bump2 => {
                let n = resample(bump_normals(&load(&l.file)?, s), size);
                for (i, px) in work.px.iter_mut().enumerate() {
                    let q = n.px[i];
                    let mut d = unit([q[0], if flip { -q[1] } else { q[1] }, q[2]]);
                    if mask.is_some() {
                        // A bump mask scales the slope exactly (rnm.py `scale_slope`).
                        let z = d[2].max(1e-6);
                        d = unit([d[0] / z * m(i), d[1] / z * m(i), 1.0]);
                    }
                    let r = rnm([px[0], px[1], px[2]], d);
                    px[..3].copy_from_slice(&r);
                }
            }
            LayerId::Bent if spec.bent.mode == BentMode::AoBlend => {
                let src = resample(load(&l.file)?, size);
                let ao = match (&job.ao, spec.bent.ao) {
                    (Some(a), true) => Some(plane(&a.file, size, a.channel as usize)?),
                    _ => None,
                };
                let power = spec.ao_power() as f32;
                for (i, px) in work.px.iter_mut().enumerate() {
                    let b = decode(src.px[i], 1.0, flip);
                    let w = match &ao {
                        Some(a) => bent_weight(s, power, a[i], m(i)),
                        None => s * m(i),
                    };
                    let r = unit([
                        px[0] * (1.0 - w) + b[0] * w,
                        px[1] * (1.0 - w) + b[1] * w,
                        px[2] * (1.0 - w) + b[2] * w,
                    ]);
                    px[..3].copy_from_slice(&r);
                }
            }
            _ => {
                let src = resample(load(&l.file)?, size);
                for (i, px) in work.px.iter_mut().enumerate() {
                    let d = decode(src.px[i], s * m(i), flip);
                    let r = rnm([px[0], px[1], px[2]], d);
                    px[..3].copy_from_slice(&r);
                }
            }
        }
    }
    Ok(())
}
