**Goal:**
- Select several textures or sets with Ctrl, Shift, Ctrl+A and Esc.
- Edit their per-texture `[files]` settings in one panel that shows mixed values and locked rows.
- Pick a map kind across selected sets.
- Use a right-click menu for Edit, Copy from active, Reset all and Select members of kind.
- Every apply is one undo step and one plan.

**Architecture:**
- A new view-model module `crates/gui/src/model/bulk.rs` holds:
  - the multi-selection (`AppModel::multi`, beside the unchanged `AppModel::selection`, which stays the active entry);
  - the pure plan `plan_bulk_edit` and the panel rows `bulk_fields`, which share one per-texture rule (`skip_of`);
  - the commands, all run through one private `AppModel::batch_edit` (the audit's accept-all pattern, made reusable);
  - the map-kind chips and the menu lists.
- The egui side adds a bulk panel (`ui/bulk_panel.rs`), modifier clicks and context menus in the two columns, and Ctrl+A/Esc. Each is a thin mapping onto model calls.

**Tech Stack:** Rust 2021 workspace (rust-version 1.88; no let-chains). `sdc-gui` (lib `sdc_gui`), egui/eframe 0.36.2, egui_kittest 0.36.2, serde_json, toml_edit, image (dev), tempfile (dev).

### Plan rulings (Note Z, written by Task 7)

- **Z1 Selection.**
  - `AppModel::selection` stays the active entry.
  - `AppModel::multi` (keys of one kind, in the order they were added) is in effect only with two or more keys that include the active one.
  - Plain click, `select_item` and `select_set` end it.
  - Ctrl toggles. Shift ranges in the displayed order (search and filters applied for textures) and keeps the active entry.
  - Ctrl+A selects what is visible. Esc clears. Neither acts while a widget has focus, a dialog or popup is open, or a texture is expanded.
  - A plan drops gone keys; a gone active key hands over to the last remaining one.
- **Z2 Bulk rule.**
  - A bulk write of a field skips a texture with no job, with the field hidden (Coverage outside cutout), with the field's `FieldView::lock`, or (for a filter write) with that filter barred.
  - One rule (`bulk::skip_of`) feeds both the panel's "applies to K of N" and the apply.
  - Locks and not-applicable cases are one category at the base. The hover lists "locked on M of N: <reason>".
- **Z3 One step, one plan.** Every bulk command runs in `AppModel::batch_edit`: one snapshot, `edit_docs` without steps or plans, one step, one `replan`. "Accept all suggestions" uses it too. `edit_docs` takes no snapshot while batching.
- **Z4 Sub-type in bulk** runs `set_field` → `edit_subtype` per texture, so the PBR follow-on applies. A texture's own write wins over a follow-on.
- **Z5 Copy from active** offers the fields of `fields::all_fields()` that the active texture's `[files]` entry sets. `allow`, `rnm.*`, `pack.*` and `channels.*` are not offered. It is textures only: for sets, Select members of kind first.
- **Z6 Reset all** removes whole `[files]` entries (acknowledgements included), clearing a `[files]` sub-type through `clear_field` first. Locks do not apply. `sdc-project.toml` is not touched.
- **Z7 Version.** It stays 0.7.0, because `ENGINE_VERSION` is part of `is_up_to_date`. No presets-changelog entry.

//! M6 Track F3a (design `2026-10-13-sdc-m6-f3a-design.md`): the multi-selection, the bulk edit plan and its
//! commands. No egui types.
use super::sets::SlotKind;
use super::{AppModel, Selection};

/// F3a D1: every selected key of one kind, the active one included, in the order they were added. It is in effect
/// only while it holds two or more keys and the active entry (`AppModel::selection`) is one of them; otherwise the
/// selection is the single active entry, as before F3a.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct MultiSelection {
    pub keys: Vec<String>,
    /// The keys are set keys (else item keys).
    pub sets: bool,
}

/// What the bulk panel keeps between frames: a new selection resets it, a plan does not.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct BulkState {
    /// F3a D3: the map-kind chip over the selected sets; `None` is All.
    pub kind: Option<SlotKind>,
    /// The last apply's result line (F3a D2: skips are reported).
    pub report: Option<String>,
}

impl AppModel {
    /// The active entry's key, when it is of the kind asked for.
    fn active_of(&self, sets: bool) -> Option<&str> {
        match (&self.selection, sets) {
            (Selection::Item(k), false) | (Selection::Set(k), true) => Some(k),
            _ => None,
        }
    }

    fn multi_in_effect(&self) -> bool {
        self.multi.keys.len() >= 2
            && self
                .active_of(self.multi.sets)
                .is_some_and(|a| self.multi.keys.iter().any(|k| k == a))
    }

    fn selected(&self, sets: bool) -> Vec<String> {
        if self.multi_in_effect() && self.multi.sets == sets {
            return self.multi.keys.clone();
        }
        self.active_of(sets)
            .map(|k| vec![k.to_string()])
            .unwrap_or_default()
    }

    /// The selected textures (item keys) in the order they were added; one or none outside a multi-selection.
    pub fn selected_items(&self) -> Vec<String> {
        self.selected(false)
    }

    /// The selected sets (set keys) in the order they were added.
    pub fn selected_sets(&self) -> Vec<String> {
        self.selected(true)
    }

    /// Whether `key` (a set key when `sets`) is selected: a tile's or a pill's highlight.
    pub fn is_selected(&self, key: &str, sets: bool) -> bool {
        if self.multi_in_effect() && self.multi.sets == sets {
            self.multi.keys.iter().any(|k| k == key)
        } else {
            self.active_of(sets) == Some(key)
        }
    }

    /// Two or more textures, or two or more sets, are selected: the centre shows the bulk panel.
    pub fn in_bulk(&self) -> bool {
        self.multi_in_effect()
    }

    fn visible_keys(&self) -> Vec<String> {
        self.visible_items()
            .into_iter()
            .map(|i| self.items[i].key.clone())
            .collect()
    }

    fn set_order(&self) -> Vec<String> {
        super::sets::views(self)
            .iter()
            .filter(|v| !v.key.is_empty())
            .map(|v| v.key.clone())
            .collect()
    }

    /// F3a D1: a click on texture `key`. Plain selects it alone; Ctrl toggles it; Shift selects the range from the
    /// active texture to it in the displayed order (search and filters applied). Shift with no active texture, or
    /// with the active one hidden, is a plain click.
    pub fn click_item(&mut self, key: &str, ctrl: bool, shift: bool) {
        let order = self.visible_keys();
        self.click(key, ctrl, shift, false, &order);
    }

    /// F3a D1: the same over the Sets column, in its display order (sets have no filter).
    pub fn click_set(&mut self, key: &str, ctrl: bool, shift: bool) {
        let order = self.set_order();
        self.click(key, ctrl, shift, true, &order);
    }

    fn click(&mut self, key: &str, ctrl: bool, shift: bool, sets: bool, order: &[String]) {
        let active = self.active_of(sets).map(str::to_string);
        let range = match (&active, shift) {
            (Some(a), true) => {
                let from = order.iter().position(|k| k == a);
                let to = order.iter().position(|k| k == key);
                from.zip(to)
                    .map(|(x, y)| order[x.min(y)..=x.max(y)].to_vec())
            }
            _ => None,
        };
        if let Some(keys) = range {
            return self.set_selection(keys, active, sets);
        }
        // A plain click, or a modifier click on the other kind: that entry alone.
        let Some(a) = active.filter(|_| ctrl) else {
            return if sets {
                self.select_set(key)
            } else {
                self.select_item(key)
            };
        };
        let mut keys = self.selected(sets);
        let next = match keys.iter().position(|k| k == key) {
            Some(i) => {
                keys.remove(i);
                if a == key {
                    keys.last().cloned()
                } else {
                    Some(a)
                }
            }
            None => {
                keys.push(key.to_string());
                Some(key.to_string())
            }
        };
        self.set_selection(keys, next, sets);
    }

    /// Select `keys` with `active` as the active entry; fewer than two keys is a single selection.
    fn put_selection(&mut self, keys: Vec<String>, active: Option<String>, sets: bool) {
        self.selection = match active {
            Some(k) if sets => Selection::Set(k),
            Some(k) => Selection::Item(k),
            None => Selection::None,
        };
        self.multi = MultiSelection { keys, sets };
        if self.multi.keys.len() < 2 {
            self.multi.keys.clear();
        }
    }

    /// `put_selection` for a new selection: the bulk panel starts over (All, no report).
    pub(super) fn set_selection(&mut self, keys: Vec<String>, active: Option<String>, sets: bool) {
        self.put_selection(keys, active, sets);
        self.bulk = BulkState::default();
    }

    /// F3a D1 Ctrl+A: every visible texture (search and filters applied), or every set when a set is the active
    /// entry. The active entry stays when it is among them; else the first becomes active.
    pub fn select_all_visible(&mut self) {
        let sets = matches!(self.selection, Selection::Set(_));
        let keys = if sets {
            self.set_order()
        } else {
            self.visible_keys()
        };
        let active = self
            .active_of(sets)
            .filter(|a| keys.iter().any(|k| k == a))
            .map(str::to_string)
            .or_else(|| keys.first().cloned());
        self.set_selection(keys, active, sets);
    }

    /// F3a D1 Esc.
    pub fn clear_selection(&mut self) {
        self.set_selection(vec![], None, false);
    }

    /// F3a D1: "12 selected", or "12 selected (4 hidden by filter)", for the column of that kind while two or
    /// more are selected there. Sets have no filter.
    pub fn selection_summary(&self, sets: bool) -> Option<String> {
        let keys = self.selected(sets);
        if keys.len() < 2 {
            return None;
        }
        let hidden = if sets {
            0
        } else {
            let shown: std::collections::HashSet<String> = self.visible_keys().into_iter().collect();
            keys.iter().filter(|k| !shown.contains(*k)).count()
        };
        Some(match hidden {
            0 => format!("{} selected", keys.len()),
            h => format!("{} selected ({h} hidden by filter)", keys.len()),
        })
    }

    /// After a plan (F3a D1, design §2.4): keys whose item or set is gone leave the multi-selection, and a gone
    /// active key hands over to the last remaining one. The chip and the report are kept.
    pub(super) fn prune_selection(&mut self) {
        if !self.multi_in_effect() {
            self.multi.keys.clear();
            return;
        }
        let sets = self.multi.sets;
        let live: Vec<String> = self
            .multi
            .keys
            .iter()
            .filter(|k| {
                if sets {
                    self.sets.iter().any(|s| &s.key == *k)
                } else {
                    self.item(k).is_some()
                }
            })
            .cloned()
            .collect();
        let active = self
            .active_of(sets)
            .filter(|a| live.iter().any(|k| k == a))
            .map(str::to_string)
            .or_else(|| live.last().cloned());
        self.put_selection(live, active, sets);
    }
}

/// The one rule (F3a D2, Note Z2): why a write of `field` skips the texture whose job and view these are, or `None`
/// when it reaches it. `plan_bulk_edit` and `bulk_fields` both call it, so the panel and the apply cannot drift.
fn skip_of(
    job: Option<&ResolvedJob>,
    view: Option<&FieldView>,
    field: &str,
    op: &BulkOp,
) -> Option<String> {
    let Some(job) = job else {
        return Some(NO_SETTINGS.into());
    };
    if field_hidden(&job.profile, field) {
        return Some(CUTOUT_ONLY.into());
    }
    let Some(view) = view else {
        return Some(format!("{field} is not a texture setting"));
    };
    if let Some(lock) = view.lock {
        return Some(lock.into());
    }
    if let (BulkOp::Set(v), "mips.filter") = (op, field) {
        let barred = serde_json::from_value::<MipFilter>(v.clone())
            .ok()
            .and_then(|f| filter_option_lock(&job.profile, f));
        if let Some(lock) = barred {
            return Some(lock.into());
        }
    }
    None
}

/// F3a D5: what a bulk edit of `field` does to each of `keys`, in order. Pure: the apply writes exactly this.
pub fn plan_bulk_edit(
    m: &AppModel,
    keys: &[String],
    field: &str,
    op: &BulkOp,
) -> Vec<(String, Change)> {
    keys.iter()
        .map(|k| {
            let job = m.item(k).and_then(|i| i.job.as_ref());
            let view = job.and_then(|j| field_view(m.target, j, field));
            let change = skip_of(job, view.as_ref(), field, op).map_or(Change::Write, Change::Skip);
            (k.clone(), change)
        })
        .collect()
}

/// One row of the bulk panel (F3a D2).
#[derive(Debug, Clone, PartialEq)]
pub struct BulkField {
    pub field: &'static str,
    pub label: &'static str,
    /// The value every texture the field applies to resolves to; `None` when they differ (mixed) or none applies.
    pub value: Option<Value>,
    /// Textures a write reaches.
    pub applies: usize,
    /// Textures it applies to whose own `[files]` entry sets it (the row's ↺ shows when > 0).
    pub edited: usize,
    /// (reason, count) of the textures a write skips, in first-seen order.
    pub skipped: Vec<(String, usize)>,
    pub total: usize,
}

impl BulkField {
    /// The note column: "— mixed", "applies to K of N", both, or nothing.
    pub fn note(&self) -> String {
        let mut parts = vec![];
        if self.value.is_none() && self.applies > 0 {
            parts.push("— mixed".to_string());
        }
        if self.applies < self.total {
            parts.push(format!("applies to {} of {}", self.applies, self.total));
        }
        parts.join(" · ")
    }

    /// The note's hover: one "locked on M of N: <reason>" line per reason.
    pub fn skipped_text(&self) -> String {
        self.skipped
            .iter()
            .map(|(r, n)| format!("locked on {n} of {}: {r}", self.total))
            .collect::<Vec<_>>()
            .join("\n")
    }
}

/// The bulk panel's rows over `keys` (F3a D2). Counts are the value-independent ones (`BulkOp::Clear`); the filter
/// lock of a picked value shows in the report.
/// shortcut: rebuilt every frame, one profile serialisation per texture; cache under `items_rev` if a selection of
/// thousands shows in a profile.
pub fn bulk_fields(m: &AppModel, keys: &[String]) -> Vec<BulkField> {
    let fields = panel_fields();
    let mut rows: Vec<BulkField> = fields
        .iter()
        .map(|&(field, label)| BulkField {
            field,
            label,
            value: None,
            applies: 0,
            edited: 0,
            skipped: vec![],
            total: keys.len(),
        })
        .collect();
    let mut values: Vec<Vec<Value>> = vec![vec![]; fields.len()];
    for k in keys {
        let job = m.item(k).and_then(|i| i.job.as_ref());
        // One profile serialisation per texture, not one per row.
        let views = job.map_or_else(Vec::new, |j| views_of(&fields, m.target, j));
        for (n, row) in rows.iter_mut().enumerate() {
            let view = views.get(n);
            match skip_of(job, view, row.field, &BulkOp::Clear) {
                Some(r) => match row.skipped.iter_mut().find(|e| e.0 == r) {
                    Some(e) => e.1 += 1,
                    None => row.skipped.push((r, 1)),
                },
                None => {
                    row.applies += 1;
                    if let Some(v) = view {
                        if !values[n].contains(&v.value) {
                            values[n].push(v.value.clone());
                        }
                        row.edited += usize::from(v.edited);
                    }
                }
            }
        }
    }
    for (row, mut vals) in rows.iter_mut().zip(values) {
        row.value = if vals.len() == 1 { vals.pop() } else { None };
    }
    rows
}

/// The members of sets `set_keys` (in that order, then member order) whose slot is `kind`; `None` is every member.
pub fn members_of(m: &AppModel, set_keys: &[String], kind: Option<SlotKind>) -> Vec<String> {
    let views = super::sets::views(m);
    let mut out: Vec<String> = vec![];
    for s in set_keys {
        let Some(v) = views.iter().find(|v| &v.key == s) else {
            continue;
        };
        for k in &v.members {
            let fits = kind.is_none() || m.item(k).and_then(super::sets::slot_of) == kind;
            if fits && !out.contains(k) {
                out.push(k.clone());
            }
        }
    }
    out
}

/// "Format: written to 9 of 12; locked on 3 of 12: BC1 only".
fn report(label: &str, plan: &[(String, Change)]) -> String {
    let n = plan.len();
    let written = plan.iter().filter(|(_, c)| *c == Change::Write).count();
    let mut skipped: Vec<(&str, usize)> = vec![];
    for (_, c) in plan {
        if let Change::Skip(r) = c {
            match skipped.iter_mut().find(|e| e.0 == r.as_str()) {
                Some(e) => e.1 += 1,
                None => skipped.push((r.as_str(), 1)),
            }
        }
    }
    let mut s = format!("{label}: written to {written} of {n}");
    for (r, k) in skipped {
        s.push_str(&format!("; locked on {k} of {n}: {r}"));
    }
    s
}

/// F3a D3: All, then one chip per slot kind present among the members of `set_keys`, in `SlotKind::ALL` order.
/// Members without a slot (raw packing sources, sub-types without a card) are under All only.
pub fn kind_chips(m: &AppModel, set_keys: &[String]) -> Vec<KindChip> {
    let mut chips = vec![KindChip {
        kind: None,
        label: "All".into(),
        members: members_of(m, set_keys, None),
        sets_with: set_keys.len(),

            .iter()

            kind: Some(kind),
            label: kind.label().into(),
            members,
            sets_with,
        });
    }

                disabled: None,

            MenuEntry {

/// F3a D4: a right-click menu drawn from `entries` under its count title; the members-of-kind entries go in a
/// "Select members of kind" submenu. The menus are lists so F3b can append. Returns the clicked action.
pub(super) fn bulk_menu(
    ui: &mut egui::Ui,
    title: &str,
    entries: &[MenuEntry],
) -> Option<MenuAction> {
    let mut picked = None;
    ui.label(egui::RichText::new(title).strong());
    ui.separator();
    let (kinds, rest): (Vec<&MenuEntry>, Vec<&MenuEntry>) = entries
        .iter()
        .partition(|e| matches!(e.action, MenuAction::SelectMembersOfKind(_)));
    for e in rest {
        let r = ui.add_enabled(e.disabled.is_none(), egui::Button::new(&e.label));
        let r = match &e.disabled {
            Some(why) => r.on_disabled_hover_text(why),
            None => r,
        };
        if r.clicked() {
            picked = Some(e.action);
            ui.close();
        }
    }
    if !kinds.is_empty() {
        ui.menu_button("Select members of kind", |ui| {
            for e in kinds {
                if ui.button(&e.label).clicked() {
                    picked = Some(e.action);
                    ui.close();
                }
            }
        });
    }
    picked
}

//! The centre panel for two or more textures or sets (M6 Track F3a, design §3-4). Drawing only: every edit is a
//! model call, made after drawing.
use super::columns::AMBER;
use super::settings_panel::{editor, RowEdit, GROUPS};
use crate::model::bulk::{bulk_fields, kind_chips, BulkField, BulkOp};
use crate::model::fields::{group_of, FieldView};
use crate::model::sets::SlotKind;
use crate::model::{AppModel, Selection};
use eframe::egui;
use engine::config::Target;
use engine::policy::ResolvedJob;
use serde_json::Value;

enum Act {
    Kind(Option<SlotKind>),
    Edit(&'static str, RowEdit),
}

pub fn draw(ui: &mut egui::Ui, model: &mut AppModel) {
    let mut acts = vec![];
    let sets = model.selected_sets();
    if sets.len() >= 2 {
        ui.heading(format!("{} sets selected", sets.len()));
        let chips = kind_chips(model, &sets);
        ui.horizontal_wrapped(|ui| {
            for c in &chips {
                let on = model.bulk.kind == c.kind;
                if ui
                    .selectable_label(on, format!("{} ({})", c.label, c.members.len()))
                    .clicked()
                {
                    acts.push(Act::Kind(c.kind));
                }
            }
        });
        if let Some(c) = chips
            .iter()
            .find(|c| c.kind == model.bulk.kind && c.sets_with < sets.len())
        {
            ui.weak(format!("applies to {} of {} sets", c.sets_with, sets.len()));
        }
    }
    let keys = model.bulk_targets();
    ui.heading(format!("{} textures selected", keys.len()));
    if let Some(r) = &model.bulk.report {
        ui.weak(r);
    }
    // Options come from the active texture's job, else the first target's (design §3.2).
    let active = match &model.selection {
        Selection::Item(k) => model.item(k).and_then(|i| i.job.clone()),
        _ => None,
    };
    let job = active.or_else(|| {
        keys.iter()
            .find_map(|k| model.item(k).and_then(|i| i.job.clone()))
    });
    match job {
        None => {
            ui.weak("None of the selected textures has settings of its own.");
        }
        Some(job) => {
            let read_only = model.toml_read_only_reason();
            if let Some(why) = &read_only {
                ui.colored_label(AMBER, why);
            }
            let (target, busy) = (model.target, model.busy());
            let rows = bulk_fields(model, &keys);
            egui::ScrollArea::vertical()
                .auto_shrink([false, false])
                .show(ui, |ui| {
                    ui.add_enabled_ui(read_only.is_none(), |ui| {
                        for g in GROUPS {
                            egui::CollapsingHeader::new(g)
                                .id_salt(("bulk", g))
                                .default_open(true)
                                .show(ui, |ui| {
                                    egui::Grid::new(("bulk-grid", g))
                                        .num_columns(4)
                                        .show(ui, |ui| {
                                            for r in rows.iter().filter(|r| group_of(r.field) == g) {
                                                if let Some(e) = row(ui, &job, target, busy, r) {
                                                    acts.push(Act::Edit(r.field, e));
                                                }
                                            }
                                        });
                                });
                        }
                    });
                });
        }
    }
    for a in acts {
        match a {
            Act::Kind(k) => model.bulk.kind = k,
            Act::Edit(f, RowEdit::Set(v)) => model.apply_bulk_edit(&keys, f, BulkOp::Set(v)),
            Act::Edit(f, RowEdit::Clear) => model.apply_bulk_edit(&keys, f, BulkOp::Clear),
        }
    }
}

/// One bulk row: the label; the editor (its mixed state, disabled when the field applies to none); the note, with
/// the skip reasons on hover; and ↺ when some texture sets the field itself.
fn row(
    ui: &mut egui::Ui,
    job: &ResolvedJob,
    target: Target,
    busy: bool,
    r: &BulkField,
) -> Option<RowEdit> {
    let mut edit = None;
    ui.label(r.label);
    let view = FieldView {
        field: r.field,
        label: r.label,
        value: r.value.clone().unwrap_or(Value::Null),
        provenance: String::new(),
        edited: r.edited > 0,
        lock: None,
    };
    let (set, _) = ui
        .add_enabled_ui(r.applies > 0, |ui| {
            editor(ui, "bulk", target, job, busy, &view, r.value.is_none())
        })
        .inner;
    if let Some(v) = set {
        edit = Some(RowEdit::Set(v));
    }
    let note = ui.label(egui::RichText::new(r.note()).small().weak());
    if !r.skipped.is_empty() {
        note.on_hover_text(r.skipped_text());
    }
    if r.edited > 0
        && ui
            .small_button("↺")
            .on_hover_text("Use the inherited value on every selected texture")
            .clicked()
    {
        edit = Some(RowEdit::Clear);
    }
    ui.end_row();
    edit
}

## Bulk editing

**Selecting several.** In the Textures or Sets column:
- **Ctrl+click** adds or removes one entry.
- **Shift+click** selects the range from the last clicked entry, in the order shown (search and filters applied).
- **Ctrl+A** selects everything shown.
- **Esc** clears the selection.

Textures and sets are never selected together. The column heading counts the selection, for example *12 selected (4 hidden by filter)*: textures hidden by the search or a filter stay selected and are edited too.

**Editing them together.** With two or more textures selected, the centre shows their settings in one panel:
- A row whose values differ reads *— mixed*.
- Picking a value writes it to every selected texture that can take it. Rows you do not touch are never written.
- A row that some textures cannot take (a field locked for them, or one that does not apply, such as *Normal handling* on a diffuse) says *applies to K of N*. Hover it for the reasons.
- After each change a line reports how many textures were written and why any were skipped.
- **↺** resets the field on all of them.

**Sets.** With two or more sets selected, a row of chips picks which of their maps to edit: *All*, *Diffuse*, *Normal _n*, *RMAOS*, and so on. Each chip shows its count, plus *applies to K of N sets* when some sets have no map of that kind.

**Right-click.** Right-clicking a selected tile or set keeps the selection; right-clicking another one selects it alone. The menu offers:
- *Edit settings for N selected*.
- *Copy settings from <texture> to N selected…*: a checklist of the active (last clicked) texture's own settings, all ticked; untick what you want to keep.
- *Reset all settings for N selected…*: removes their `sdc.toml` entries after asking.
- For sets, *Select members of kind*, which turns the selection into those textures.

Every change of this kind is one undo step, and the folder is planned once. A read-only `sdc.toml` takes no bulk change. The Advanced drawer still edits one texture at a time.
